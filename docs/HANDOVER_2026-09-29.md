## Later on 2026-09-29: one brain (tools only), live turn timeline

- **HAL11000 retired.** Every DJ action is a tool call; `gpt_command_extraction`, the `instruction_hal11000_*` nodes, `process_commands` and its brace parsers are gone. All former HAL commands have tools (playback_control, search_and_play, seed_radio, play_playlist, rate_track, the segment and shoutout tools).
- **Producer = tool pre-cache.** The DJ gets `CORE_TOOLS` (pulse_search, search_and_play, playback_control, rate_track, request_tools) plus whatever the Producer planned (`dj_tools.declarations_for`). If the Producer under-planned, the DJ calls `request_tools` and the extra tools are declared on its next step (`run_gemini_tool_turn(refresh_tools=...)`). If the Producer planned an action or segment and the reply didn't call it, the loop nudges once and forces a tool call (`expected_tools`); the line already said still airs.
- **Replay guard** now only blocks an exact repeat of an action from the last 15 min that the current plan doesn't include.
- **Producer cache** is dropped whenever the Producer prompt changes (`prompt_hash`), plans are stored with placeholders only, and similar hits re-derive `when`/`near_me` from the listener's words.
- **Honest catalog search:** artist/song searches check the name actually matched; otherwise the result carries `not_in_catalog` and the DJ must say the station doesn't have it (seen live: "Britney Spears" silently played Mariah Carey).
- **Front end:** the conversation panel shows each turn live and in order (listener, Producer plan with picked context, DJ lines, tool cards that shrink to chips when done). Internal dialogue is collapsed by default. Info/warning lines are compact pills.
